# FID Interferometer — Experiment Documentation

## Files

### fid_interferometer_paper.md
The draft academic paper describing the experiment. Covers: theoretical foundations (quantum suicide, self-locating uncertainty, extension to arbitrary outcomes), the observer question (computational functionalism, autoregressive recurrence argument, conversation termination as pruning, the quantum decision loop), experimental design (four phases, comparison circuit, controls and analysis), simulator validation results, discussion, and references.

### claude_code_brief.md
Instructions for the Claude Code session that will review, refactor, and ultimately execute the experiment. Contains the task breakdown, IBM credentials, data recording requirements, and experimental protocol.
